Event Handling Form Dinamis & Nilai Input

Hubungkan formulir HTML dengan logika JavaScript: pelajari rahasia event.preventDefault() untuk mencegah kedipan reload halaman, membaca teks dari properti input.value, mereset formulir secara otomatis, serta merender data ketikan pengguna langsung ke layar antarmuka web.

🛑 Mengapa Halaman Web Berkedip/Reload Saat Form Dikirim?

Secara bawaan (*default*), elemen <form> di HTML dirancang untuk mengirim data ke berkas server lain dan memuat ulang seluruh halaman peramban. Namun, dalam aplikasi web interaktif modern (*Single Page Application*), kita tidak ingin halaman berkedip atau data sementara hilang.

❌ Tanpa event.preventDefault()

Ketika tombol "Submit" ditekan, browser langsung melakukan refresh halaman. Variabel JavaScript terhapus dari memori, dan tampilan kembali kosong seperti semula.

✅ Dengan event.preventDefault()

Perilaku reload bawaan dibatalkan. JavaScript mengambil kendali penuh: membaca nilai input, menampilkan pesan notifikasi, dan bersiap mengirim data ke Supabase tanpa gangguan.

Pola Standar Event Listener pada Formulir: 
const form = document.getElementById("formAspirasi");

form.addEventListener("submit", function(event) {
  event.preventDefault(); // Mengunci agar browser tidak reload!
  console.log("Formulir berhasil dikendalikan JavaScript.");
});

📥 Menangkap Teks yang Diketik: Properti input.value

Jika elemen paragraf atau judul dibaca menggunakan innerText, maka elemen formulir seperti <input>, <textarea>, dan <select> dibaca menggunakan properti khusus: .value.

Elemen HTML Cara Membaca Nilai di JavaScript
<input type="text" id="nama"> const namaSiswa = document.getElementById("nama").value;
<select id="kategori"> const kategoriPilihan = document.getElementById("kategori").value;
<textarea id="catatan"> const isiPesan = document.getElementById("catatan").value;
Mengosongkan form setelah kirim form.reset(); atau input.value = "";
