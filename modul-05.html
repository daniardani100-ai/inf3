Logika JavaScript & Manipulasi DOM Dasar

Saatnya memberi "otak" pada halaman webmu! Pelajari bagaimana JavaScript mengubah halaman HTML statis menjadi interaktif: memahami variabel (let & const), menyeleksi elemen melalui Document Object Model (DOM), mendengarkan klik tombol (Event Listener), hingga memanipulasi teks dan gaya secara langsung.

⚡ JavaScript: Otak dan Sistem Saraf Halaman Web

Jika HTML adalah dinding bata rumah dan CSS adalah cat warna yang mempercantik, maka JavaScript adalah instalasi listrik, saklar otomatis, dan sensor pintar.

1. Tanpa JavaScript

Halaman web bersifat pasif. Tombol yang diklik tidak melakukan apa-apa selain berpindah halaman atau me-refresh layar.

2. Dengan JavaScript

Halaman dapat bereaksi terhadap tindakan manusia: memvalidasi teks tanpa reload, menghitung total belanjaan, dan memunculkan pop-up interaktif.

3. Hubungan ke Supabase

JavaScript adalah jembatan yang bertugas mengambil data ketikan siswa lalu mengirimkannya ke database cloud Supabase.

Cara Menulis JavaScript di Dokumen HTML: Gunakan tag pembungkus <script> ... </script> yang biasanya diletakkan tepat sebelum tag penutup </body> agar seluruh tampilan web selesai dimuat terlebih dahulu.

📦 Variabel Modern: Wadah Penyimpan Data Sementara

Variabel diibaratkan sebagai kotak kardus yang diberi label nama untuk menyimpan nilai di memori RAM komputer. Dalam JavaScript modern (ES6+), kita menggunakan const dan let:

🔒 const (Konstanta - Nilai Tetap)

Digunakan untuk data yang nilainya tidak boleh diubah setelah dibuat. Sangat disarankan untuk menyimpan elemen HTML atau URL API.
const namaSekolah = "SMAN 1 Digital";

🔄 let (Variabel Dinamis)

Digunakan untuk data yang nilainya bisa berubah sewaktu-waktu, misalnya penghitung skor kuis atau status tombol.
let jumlahHadir = 0; jumlahHadir = jumlahHadir + 1;

3 Tipe Data Paling Dasar:

Teks (String)

Diapit tanda petik.
"Budi" atau 'Kelas 12'

Angka (Number)

Bisa bilangan bulat atau desimal tanpa tanda petik.
95 atau 3.75

Logika (Boolean)

Hanya bernilai benar atau salah.
true atau false

🌳 Document Object Model (DOM): Jembatan Penghubung

Ketika file HTML dibuka di browser, browser mengubah tag-tag HTML tersebut menjadi struktur pohon objek yang disebut DOM (Document Object Model). Melalui DOM, JavaScript bisa "melihat" dan "mengubah" elemen HTML mana pun.

Perintah JavaScript Fungsi Nyata
document.getElementById('idElemen') Menangkap elemen HTML berdasarkan atribut ID uniknya.
elemen.innerText = "Teks Baru" Mengganti isi teks tulisan di layar secara seketika.
elemen.style.color = "red" Mengubah gaya visual atau warna elemen langsung dari skrip.
tombol.addEventListener('click', aksi) Memasang sensor pendengar klik: jalankan fungsi ketika tombol ditekan.
