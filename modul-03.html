Styling Antarmuka & Tata Letak Responsif (CSS Flexbox)

Ubah halaman HTML polos menjadi aplikasi web modern yang sedap dipandang: kuasai selektor CSS, konsep Box Model (margin, padding, border), serta teknik tata letak modern berbasis CSS Flexbox agar formulir dan kartu data tampil proporsional di layar laptop maupun ponsel cerdas.

🎨 Dasar Sintaks CSS: Memberi Gaya pada Kerangka HTML

CSS (Cascading Style Sheets) bertindak seperti cat, keramik, dan penataan interior pada sebuah bangunan rumah. CSS memberi tahu browser bagaimana elemen HTML harus ditampilkan: jenis font, warna latar, spasi, hingga ukuran tombol.

🏷️ 1. Selektor Elemen Tag

Membidik seluruh elemen dengan nama tag yang sama.
p { color: #CBD5E1; }

🎯 2. Selektor Kelas (.class)

Membidik sekelompok elemen yang memiliki tanda class khusus.
.card-box { padding: 16px; }

🆔 3. Selektor ID (#id)

Membidik tepat satu elemen unik di dalam dokumen.
#btnKirim { background: blue; }

Cara Terbaik Menyematkan CSS untuk Pemula: Tuliskan aturan CSS di dalam tag <style> ... </style> yang diletakkan di dalam blok <head> dokumen HTML-mu (Internal Styling).

📦 Anatomi Box Model: Mengatur Spasi Elemen

Setiap elemen di halaman web (tombol, kartu, judul, kotak teks) diperlakukan oleh browser sebagai sebuah kotak persegi 4 lapis:

MARGIN (Jarak Luar Elemen dengan Elemen Lain)
BORDER (Garis Batas / Bingkai Kotak)
PADDING (Bantalan / Jarak Dalam antara Teks & Garis Batas)
CONTENT (Isi Teks / Tombol / Gambar)
📏 Perbedaan Margin vs Padding

Padding: Menambah ruang lega di dalam kotak tombol/kartu agar tulisan tidak menempel pada dinding garis tepi.
Margin: Menciptakan celah jarak di luar kotak agar antarkartu tidak saling bertabrakan.

✨ Sudut Membulat (border-radius)

Gunakan properti border-radius: 12px; untuk mengubah sudut kotak yang tajam dan kaku menjadi melengkung halus khas antarmuka modern.

🚀 Panduan Praktik Nyata: Menata Tampilan Formulir Web

Terapkan gaya modern pada file proyek yang telah kamu bangun pada Modul 01 dan Modul 02:

  1. Buka File Proyekmu:

    Buka berkas index.html di aplikasi teks editor VS Code atau Notepad.

  2. Bungkus Formulir dengan Elemen <div class="form-card">:

    Bungkus seluruh tag <form> yang telah kamu buat dengan kontainer <div> agar mudah diberi gaya kotak kartu.

  3. Sisipkan Tag <style> di dalam <head>:

    Tambahkan blok <style> dan atur latar belakang (background-color), batas kotak (border-radius), serta ruang bantalan (padding: 20px;).

  4. Ratakan Formulir Menggunakan Flexbox:

    Atur elemen body dengan properti display: flex; justify-content: center; agar formulir berada tepat di tengah layar laptop atau monitor lab.

  5. Simpan & Refresh Halaman Browser:

    Tekan Ctrl + S dan periksa perubahan visualnya pada browser. Webmu kini tidak lagi terlihat seperti dokumen polos tahun 90-an!
