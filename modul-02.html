Formulir Input Data Interaktif (Forms & Controls)

Pelajari pintu gerbang pengumpulan data pengguna: membungkus kolom input dengan tag <form>, mengeksplorasi ragam tipe input, dropdown, area teks panjang, tombol pengirim, serta validasi bawaan browser sebelum data diteruskan ke basis data cloud.

📦 Analogi Formulir Web: Lembar Isian Buku Tamu Sekolah

Jika Modul 01 mengajarkan kita membuat tulisan yang hanya bisa dibaca oleh pengunjung, Modul 02 ini membuka kemampuan web untuk mendengarkan dan mengumpulkan data dari pengunjung.

📋 1. Tag <form> (Map Berkas)

Wadah pembungkus yang bertugas mengumpulkan semua kolom isian menjadi satu paket data utuh saat tombol submit ditekan.

✍️ 2. Kolom Isian (Controls)

Komponen tempat pengguna mengetik teks, memilih tanggal, mencentang opsi, atau menulis aspirasi panjang.

🚀 3. Submit Button (Kurir Pengirim)

Tombol pemicu yang memberi sinyal ke JavaScript atau database bahwa isian formulir sudah selesai diketik dan siap disimpan.

Penting untuk Proyek Supabase Nanti: Seluruh data formulir yang kamu rangkai di modul ini nantinya akan ditangkap oleh JavaScript (Modul 06) dan dikirim langsung ke baris tabel Supabase PostgreSQL (Modul 13).

🎛️ Ragam Elemen Input & Kontrol Antarmuka

HTML menyediakan elemen input spesifik agar keyboard ponsel atau komputer otomatis menyesuaikan tipe data yang dimasukkan pengguna:

Elemen / Tipe Contoh Kode Kegunaan Nyata
type="text" <input type="text"> Isian satu baris untuk nama lengkap, judul buku, username.
type="number" <input type="number"> Isian angka: umur, jumlah barang kantin, nominal uang kas.
type="email" <input type="email"> Alamat surel (otomatis memvalidasi tanda @ di browser).
<textarea> <textarea rows="3"></textarea> Kotak multi-baris untuk saran, deskripsi keluhan, aspirasi.
<select> <select><option>...</option></select> Pilihan menu tarik-turun (dropdown), misal memilih kelas atau kategori.
Pasangan Tag <label> dan Atribut "id": Selalu gunakan tag <label for="namaId"> untuk memberi keterangan nama kolom. Saat teks label diklik di layar HP, kursor otomatis masuk ke kotak input yang dituju!

⚙️ Atribut Kunci & Validasi Bawaan Browser

Tanpa menulis kode JavaScript rumit, browser dapat mencegah pengguna mengirim formulir yang masih kosong atau formatnya keliru menggunakan atribut bawaan berikut:

🔒 required

Menandai bahwa kolom tersebut wajib diisi. Jika dibiarkan kosong, browser akan menampilkan pop-up peringatan otomatis saat tombol kirim ditekan.

💡 placeholder

Teks samar abu-abu di dalam kotak input sebagai contoh format pengisian yang hilang saat pengguna mulai mengetik.

🆔 id & name

id digunakan oleh JavaScript dan CSS untuk membidik elemen spesifik, sedangkan name menjadi penanda kunci saat formulir diproses backend/server.

📏 min & max / maxlength

Membatasi batas angka minimum/maksimum atau batas jumlah karakter teks yang boleh diketikkan siswa.

<!-- Contoh Formulir Validasi Lengkap -->
<label for="inputNama">Nama Lengkap:</label>
<input type="text" id="inputNama" name="nama" placeholder="Contoh: Budi Santoso" required>

🚀 Panduan Praktik Nyata: Formulir Buku Tamu / Kas Kelas

Buka berkas latihanmu di komputer lab atau laptop dan ikuti alur berikut:

  1. Buka Proyekmu di VS Code / Notepad:

    Buka berkas index.html yang sudah kamu buat pada Modul 01.

  2. Tambahkan Wadah Formulir di dalam <body>:

    Tuliskan tag pembungkus <form id="formAspirasi"> ... </form> tepat di bawah paragraf perkenalan profilmu.

  3. Sisipkan Minimal 3 Elemen Input:

    Sertakan 1 input teks (Nama), 1 dropdown <select> (Pilihan Kategori), dan 1 <textarea> (Pesan).

  4. Pasang Validasi "required" & Tombol Submit:

    Tambahkan atribut required agar kotak tidak boleh kosong, lalu akhiri dengan tag <button type="submit">Kirim Data</button>.

  5. Simpan & Uji Coba di Browser:

    Tekan Ctrl + S, lalu refresh browsermu. Coba tekan tombol kirim tanpa mengisi nama untuk membuktikan validasi browser bekerja!
