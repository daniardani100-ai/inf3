Git & Publikasi Online di GitHub Pages

Saatnya membagikan karyamu ke seluruh dunia! Pahami cara kerja Version Control System (Git), bedakan penyimpanan lokal dengan repositori cloud di GitHub, serta aktifkan hosting gratis GitHub Pages agar halaman webmu memiliki URL resmi yang bisa diakses dari HP siapa pun.

🐙 Git vs GitHub: Apa Bedanya?

Banyak pemula mengira Git dan GitHub adalah hal yang sama. Padahal keduanya memiliki peran yang sangat berbeda namun saling melengkapi dalam rekayasa perangkat lunak:

🧰 1. Git (Mesin Perekam Jejak / Offline)

Aplikasi pelacak revisi kode yang berjalan langsung di komputer/laptopmu. Mirip fitur Save As / Checkpoint dalam game, Git mencatat setiap perubahan kode sehingga kamu bisa kembali ke versi sebelumnya jika terjadi error.

☁️ 2. GitHub (Rumah Cloud / Online)

Layanan berbasis web tempat kita menyimpan berkas repositori Git di cloud. GitHub memungkinkan kolaborasi tim programmer di seluruh dunia dan menyediakan fitur hosting web statis gratis bernama GitHub Pages.

Format Alamat Web GitHub Pages Siswa:
Website yang kamu hosting di GitHub Pages akan memiliki pola URL resmi:
https://[username-kamu].github.io/[nama-repositori]/

🚀 Mengaktifkan GitHub Pages (Cara Praktis Web Upload)

Bagi siswa yang belum memasang Git di komputer laboratorium, GitHub menyediakan fitur unggah berkas langsung melalui antarmuka web:

  1. Buat Repositori Baru di GitHub:

    Buka github.com, klik ikon "+" $\rightarrow$ New repository. Beri nama repositori (contoh: aplikasi-web-12) dan pastikan memilih opsi Public.

  2. Unggah Berkas Proyek:

    Klik link "uploading an existing file". Seret file index.html, modul-01.html, dan file proyek lainnya ke kotak unggahan, lalu klik Commit changes.

  3. Buka Menu Settings Repositori:

    Pada tab menu atas repositori, klik Settings (ikon roda gigi), lalu pilih menu Pages di bilah navigasi sebelah kiri.

  4. Pilih Sumber Branch:

    Pada bagian Build and deployment $\rightarrow$ Branch, ubah pilihan dari None menjadi main (folder /root), lalu klik tombol Save.

  5. Tunggu URL Publik Muncul:

    Refresh halaman setelah 1–2 menit. Tautan websitemu akan muncul dengan warna hijau: "Your site is live at https://..."!

🛠️ Mengatasi Masalah Umum: Error 404 Not Found

Jika URL GitHub Pages dibuka tetapi memunculkan layar "404 There isn't a GitHub Pages site here", biasanya disebabkan oleh 3 kekeliruan berikut:

⚠️ 1. Huruf Besar pada Nama File

GitHub Pages membedakan huruf besar dan kecil (*case sensitive*). File harus bernama index.html seluruhnya dengan huruf kecil, bukan Index.html atau INDEX.HTML.

📁 2. File Berada di Dalam Subfolder

File index.html wajib berada di folder terluar (root). Jika kamu memasukkannya ke dalam folder baru (misal folder proyek/index.html), halaman utama tidak akan terbaca.

⏱️ 3. Proses Deployment Masih Antre

Saat pertama kali disimpan, server GitHub butuh waktu 30 hingga 90 detik untuk merakit situsmu. Cek indikator lingkaran oranye/hijau di menu Actions.

📋 Tugas Praktik Pekan Ini: Rilis Web Pertama

Lakukan tahapan berikut di laboratorium sekolah atau laptop pribadi:

  1. Daftar atau masuk ke akun GitHub masing-masing di github.com.
  2. Buat satu repositori publik khusus tugas informatika kelas 12.
