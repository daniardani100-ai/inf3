Anatomi Dokumen Web & Tag Semantik HTML5

Pelajari fondasi utama perancangan web: memahami analogi kerangka rumah, menyusun dokumen index.html pertama di teks editor, hingga menguji pemahaman dengan kuis interaktif 10 soal.

🏠 Analogi Sederhana: Website Ibarat Membangun Rumah

Membangun web terintegrasi Supabase memiliki konsep serupa dengan mendirikan rumah tinggal:

🦴 1. HTML (Kerangka & Bata)

HyperText Markup Language: Pondasi, susunan bata, dinding, dan sekat ruang. Menentukan letak judul, form, dan tombol.

🎨 2. CSS (Cat & Desain)

Cascading Style Sheets: Warna tembok, keramik lantai, dan layout ruangan agar tampak estetik dan responsif.

⚡ 3. JavaScript (Kelistrikan)

Logic & Behavior: Saklar lampu otomatis dan kran pintar. Mengatur aksi tombol mengirim data ke cloud database.

🧬 Kerangka Anatomi Wajib Setiap Dokumen HTML5

Semua dokumen web dimulai dengan deklarasi tipe dokumen dan pasangan pembungkus berikut:

<!DOCTYPE html>
<html lang="id">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Judul Halaman di Tab Browser</title>
  </head>
  <body>
    <h1>Halo, Selamat Datang di Web Kelas 12!</h1>
  </body>
</html>

📝 Tag Semantik Teks & Daftar List

📌 Heading (Judul Bertingkat)

Gunakan <h1> untuk judul paling utama, disusul <h2> hingga <h6> untuk sub-judul.

📄 Paragraf & List

Gunakan <p> untuk paragraf, <ul> untuk list poin bulat, dan <ol> untuk list angka berurutan.

🧪 Live Code Sandbox: Uji Coba di Browser

Ubah teks di editor sebelah kiri, lalu klik "Jalankan Kode ▶" untuk melihat perubahannya langsung.

🚀 Panduan Praktik Nyata di Komputer Sekolah / Laptop

  1. Buka aplikasi VS Code atau Notepad bawaan Windows.
  2. Ketik struktur dokumen lengkap <!DOCTYPE html>.
  3. Simpan berkas melalui File → Save As dengan nama persis index.html (pilih Save as type: All Files (*.*)).
  4. Buka folder penyimpanan lalu klik ganda file index.html untuk membukanya di browser.
